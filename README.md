# Desenvolver Sistema com Delphi e SQL Server na Prática

Repositório destinado aos meus estudos do curso **Desenvolver Sistema com Delphi e SQL Server na Prática** da Udemy.

## Objetivos

- Aprender desenvolvimento de aplicações Desktop com Delphi
- Trabalhar com SQL Server
- Aplicar boas práticas de programação
- Versionar projetos utilizando Git e GitHub

## Tecnologias

- Delphi
- SQL Server
- Git
- GitHub

## Estrutura

- `AulaXX` → Projetos desenvolvidos em cada módulo
- `Banco` → Scripts e backups do banco de dados
- `ProjetoFinal` → Sistema desenvolvido ao final do curso
- `docs` → Anotações e imagens
